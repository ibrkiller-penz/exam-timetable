# 인쇄물 만드는 규칙

종이는 화면과 달리 **고칠 수 없다.** 감독 선생님이 시험장에서 들고 서서 보고,
학생이 복도에서 제 자리를 찾는 종이다. 아래 규칙은 그 자리에서 실제로 겪은
문제를 하나씩 고쳐 얻은 것이다. 새로 만들 때도, 고칠 때도 이대로 한다.

## 1. 인쇄는 화면을 그대로 뜬다

브라우저 인쇄는 화면과 **다른 규칙으로 다시 그린다.** 표 너비·줄바꿈·글자
크기가 조금씩 달라지면서 오른쪽이 잘리거나 한 줄이 다음 장으로 넘어간다.
`@page` 와 여백을 아무리 맞춰도 브라우저·프린터마다 결과가 달라 끝이 없다.

**그래서 화면에 그려진 한 장을 사진처럼 떠서 A4 에 얹는다.** 화면에서 잘
보이면 종이에서도 똑같이 나온다. 인쇄와 PDF 가 같은 길을 쓰므로 둘이
어긋날 수도 없다.

여기서 따라오는 규칙:

- **`print:` 변형(Tailwind)은 죽은 코드다.** `print:text-[12px]`, `print:p-3`,
  `print:border-none` 은 이제 아무 일도 하지 않는다. 화면에 보이는 값이 곧
  종이에 찍히는 값이다. 새로 달지 말고, 보이면 지운다.
- **화면용 장식은 뜨기 전에 지운다.** 테두리·그림자·둥근 모서리가 그대로
  찍힌다. 인쇄용 CSS 가 아니라 캡처 중에만 붙는 class 에서 지운다.
- **창이 좁으면 페이지가 줄어든다.** `max-width:100%` 때문에 1024px 창에서
  210mm 가 172mm 로 찌그러지고, 그 상태로 뜨면 표가 다시 접힌다. 뜨는 동안만
  원래 A4 폭으로 되돌린다.

## 2. 종이 한 장의 생김새

- 한 장은 **늘 A4 비율을 정확히 지킨다** (794×1123px = 210×297mm).
  높이를 내용에 맞춰 줄이면 장마다 그림 비율이 달라져, 어떤 장은 크고 어떤
  장은 작게 찍힌다.
- 내용은 **세로 가운데**에 둔다. `display:flex; flex-direction:column;
  justify-content:center`. 위아래 여백이 같은지 실제로 재서 확인한다.
- **표를 늘려 종이를 꽉 채우지 않는다.** 남는 높이를 줄마다 나눠 가지면
  줄 수에 따라 줄 높이가 들쭉날쭉해진다(스무 명이면 38px, 서른 명이면 30px).
  줄 높이는 그대로 두고 덩어리를 가운데 놓는 편이 늘 낫다.
  - 예외: 좌석배치도처럼 **칸이 교실을 본뜬** 장은 채워야 한다. 그때만
    안쪽 격자에 `flex:1` 을 준다.
- 종이 가장자리 여백은 **5mm**. 프린터가 물리적으로 못 찍는 자리를 피하면서
  종이를 최대한 쓴다. 이 값은 인쇄와 PDF 가 **같은 곳에서** 가져가야 한다.

## 3. 표의 선 — 굵기가 아니라 위계

선을 다 같은 굵기로 그으면 눈이 어디에 머물지 모른다. **세 단계**로 나눈다.

| 자리 | 굵기·색 | 왜 |
|---|---|---|
| 줄과 줄 사이 | **1px 연회색** `#b6c0cc` | 눈이 줄을 따라가게만 하고 나서지 않는다 |
| **다섯 줄마다** | **2px 진한 검정** `#0f172a` | 5·10·15…에서 확실히 갈려야 인원을 셀 때 눈이 미끄러지지 않는다 |
| 제목 줄 아래 | **4px 이중선** `#0f172a` | 머리글과 내용의 경계 |
| 바깥 테두리 | **2.5px 진한 검정** | 표가 어디서 끝나는지 |

두 가지를 꼭 지킨다.

- **굵기만으로 구분하지 않는다.** 1px 과 1.5px 는 인쇄에서 뭉개져 똑같아
  보인다. **색을 연하게** 해서 차이를 낸다.
- **마지막 줄에는 다섯 줄 선을 긋지 않는다.** 바깥 테두리와 겹쳐 두꺼워진다.

```css
.sheet-table { border-collapse: collapse; border: 2.5px solid #0f172a; font-size: 16px; }
.sheet-table th, .sheet-table td { border: 1px solid #b6c0cc; vertical-align: middle; }
.sheet-table thead > tr > * { border-color: #0f172a; }
.sheet-table thead tr:last-child > * { border-bottom: 4px double #0f172a; }
.sheet-rows-5 tbody tr:nth-child(5n):not(:last-child) > * { border-bottom: 2px solid #0f172a; }
```

**한 곳에서 정하고 class 만 붙인다.** 표마다 Tailwind 로 `border-2
border-gray-800 divide-y` 를 따로 쓰면 곧 제각각이 된다. 이미 그렇게 쓰인
표가 많으면 `!important` 로 덮어 한 규칙이 이기게 한다.

## 4. 글자

**크기를 한 곳에서 정한다.** 종이마다 15px·15.5px·16px 가 섞이면 같은
고사에서 나온 서류로 보이지 않는다.

| 무엇 | 크기 |
|---|---|
| 고사 제목(작은 머리글) | 17px, 회색 |
| 큰 제목 | 46px, 굵게 |
| 부제(반·교시·과목) | 22px |
| 정보 칸 | 15px (강조 항목 19px) |
| 표 본문 | 16px |
| 표 머리글 | 15px |
| 강조 칸(성명·좌석) | 18~19px |
| 각주·안내 | 13px |

- **칸 안에서 글자는 늘 세로 가운데**(`vertical-align: middle`). 줄 높이를
  키우면 글자가 위로 붙는다.
- **고사 제목을 모든 장에 넣는다.** 어느 고사의 서류인지 종이만 보고 알아야
  한다. 다만 큰 제목 자체가 고사 제목인 장에서는 두 번 쓰지 않는다.
- **글자 수와 상관없이 같은 폭으로** 보여야 하는 자리(봉투 라벨의 과목명)는
  글자 수로 크기를 어림하지 말고 **실제로 재서** 맞춘다. 칸 너비의 80% 를
  채우되 칸 높이로도 막는다. 글자 모양을 늘이지 않는다(가로로 찌그러진다).

## 5. 한 장에 몇 줄

- 줄 수를 **못 박는다.** 사람이 적어도 칸 수는 같아야 종이 모양이 일정하다.
  (고사실 명단은 한 칸 20줄, 두 칸 40명까지.)
- 넘치면 장을 나누고 **`#1 / 2`** 를 머리글에 붙인다.
- 20명 이하면 한 칸으로 **가운데** 놓는다. 다 들어가는데 두 칸으로 벌리면
  오른쪽이 통째로 비어 종이가 한쪽으로 쏠려 보인다.
- 칸 너비를 `colgroup` 으로 못 박는다. 안 그러면 성명이 두 줄로 접혀 줄
  높이가 배가 되고, 한 장에 실리는 줄 수가 줄어든다.

## 6. 버튼과 머리줄 (화면 쪽)

인쇄물 화면은 **`[번호] 제목 / 고르는 칸 … 오른쪽에 버튼`** 한 모양으로
맞춘다. 버튼 순서도 고정한다.

```
[엑셀]  [PDF 저장] [전체 저장]  [인쇄] [전체 인쇄]
```

**'전체'는 그 화면에 여러 장이 있을 때만** 낸다. 한 장짜리에 전체 버튼을
두면 같은 것을 두 번 누르게 된다.

## 7. 고치기 전에 재라

눈으로 보고 고치지 말고 **숫자로 확인한다.** 브라우저에서:

```js
document.documentElement.classList.add('capturing');
const el = document.querySelector('.print-page');
const r = el.getBoundingClientRect();
({ w: r.width, h: r.height, ratio: (r.width / r.height).toFixed(3),  // 0.707 이어야 A4
   topGap: el.firstElementChild.getBoundingClientRect().top - r.top,  // 위아래가
   bottomGap: r.bottom - el.lastElementChild.getBoundingClientRect().bottom }); // 같아야 가운데
```

## 8. 겪었던 함정

- **좌석배치도가 통째로 비어 나왔다.** 자리가 비었는지를 *이름이 있는가*로
  판단했는데, 나이스에서 성명을 내려받지 않은 자료에서는 모든 자리가 빈 칸이
  됐다. **사람이 앉았는지**로 판단한다. 표시할 값이 비어 있는 것과 자료가
  없는 것은 다르다.
- **창 안의 종이가 아래로 잘렸다.** 스크롤 상자에 `print-page` 를 붙여
  `min-height:297mm` 때문에 상자가 줄어들지 못했다. 종이는 안쪽에 붙이고
  상자는 `flex-1 min-h-0` 으로 편다.
- **전체 출력이 한 장만 나왔다.** `printingAll` 을 선언만 하고 렌더에 쓰지
  않았다. '전체'가 있는 화면은 실제로 여러 장이 그려지는지 세어 본다.
- **한 번에 인쇄하는 장들은 종이 방향이 같아야 한다**(`@page` 는 하나뿐).
  섞이면 가로가 필요한 장 하나 때문에 모두 눕혀야 한다.
