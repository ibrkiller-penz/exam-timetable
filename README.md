# 📚 고등학교 시험시간표 및 학생 배치 관리 시스템 (Exam Timetable)

NEIS 학생 편성 엑셀 데이터를 기반으로 시험시간표 편성, 동시시험 불가 과목 분석, 분반/고사실 자동배치 및 출력 장부(라벨, 좌석표, 명렬표 등)를 원스톱으로 처리하는 시스템입니다.

- **GitHub 저장소**: [https://github.com/ibrkiller-penz/exam-timetable](https://github.com/ibrkiller-penz/exam-timetable)
- **온라인 웹 버전**: [https://examtable.web.app](https://examtable.web.app)

---

## 🏠 집에서 이어서 작업하는 3가지 방법

### 방법 1. 웹 브라우저에서 바로 사용 (가장 간편한 방법 ⭐ 추천)
별도의 개발 환경이나 프로그램 설치 없이 크롬, 엣지, 웨일 등 웹 브라우저에서 바로 작업하실 수 있습니다.
1. 웹 브라우저에서 **[https://examtable.web.app](https://examtable.web.app)** 접속
2. 상단 메뉴의 **[📂 불러오기]** 클릭 후 학교에서 저장해둔 `.json` 파일 선택
   (또는 상단 **☁️ 클라우드** 버튼을 눌러 저장된 백업 불러오기)
3. 작업 후 상단 **[💾 저장]**을 눌러 파일로 다운로드하거나 클라우드에 즉시 저장

---

### 방법 2. 무설치 PC 프로그램(ZIP)으로 집 PC에서 실행
학교 컴퓨터 바탕화면에 생성된 **`시험시간표_PC프로그램(전체배포용).zip`** (약 107MB) 파일을 USB나 메일, 클라우드로 가져가서 실행합니다.
1. 집 컴퓨터의 원하는 폴더에 압축 해제
2. 폴더 내 **`시험시간표.exe`** 더블 클릭하여 실행
3. 오프라인 상태에서도 동일하게 모든 기능(엑셀 불러오기, 자동배치, 인쇄 라벨 생성) 동작

---

### 방법 3. 집 PC에서 Git 클론 후 개발/로컬 실행
Node.js(v18 이상)가 설치되어 있는 경우 소스코드를 받아 직접 실행할 수 있습니다.

```bash
# 1. 저장소 복제 (Git Clone)
git clone https://github.com/ibrkiller-penz/exam-timetable.git

# 2. 프로젝트 폴더 이동
cd exam-timetable

# 3. 의존성 패키지 설치
npm install

# 4. 웹 개발 모드로 실행 (브라우저에서 열기)
npm run dev

# 5. 또는 Electron 데스크톱 창으로 실행
npm run local
```

## 💾 작업 데이터 백업 및 연동 팁
- **작업 파일 저장 (`.json`)**:
  - 화면 상단 헤더 우측의 **[💾 저장]** 버튼을 누르면 현재까지의 모든 설정(과목, 고사실, 교시별 배치, 학생 이동 내역)이 담긴 JSON 파일이 생성됩니다.
  - 집에서 이 JSON 파일만 불러오면 1초 만에 100% 동일한 화면 상태가 복원됩니다.
- **클라우드 실시간 동기화**:
  - 상단의 `☁️ 클라우드 저장` 기능으로 Firebase 서버에 안전하게 자동 저장되므로 다른 PC에서도 즉시 이어서 작업할 수 있습니다.
